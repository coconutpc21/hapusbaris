1 · File
Pilih file Excel Format .xlsx atau .xls
File .xls lama bisa langsung dipilih. File .xls dibaca lalu dikonversi otomatis di perangkat ini, dan hasilnya disimpan sebagai .xlsx. Untuk .xls, isi, format angka/tanggal, lebar kolom, dan sel gabungan terbawa, tetapi warna, huruf tebal, dan border bisa hilang. Jika format harus utuh, simpan dulu sebagai .xlsx lewat Excel (File → Save As → Excel Workbook (*.xlsx)).
